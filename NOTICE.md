# Origin and attribution

The maintained toolkit was first authored for the CVPR_3D readiness work. This
repository is a selected-file publication of that new MIT-licensed layer, with
standalone documentation and tests. The original copyright notice is retained.

`SOURCE_PROVENANCE.json` records the exact source commit, selected paths and
SHA-256 values at import. That commit may remain local to the original archive;
the included receipt does not depend on its public availability. Future toolkit
changes are recorded in this repository's own history; the receipt is an import
record, not a hash assertion about every later version.

The historical work remains separately preserved at
[MatteoPhan926/CVPR_3D](https://github.com/MatteoPhan926/CVPR_3D).
It is not an installation prerequisite or part of this distribution. The link
provides attribution only and does not endorse its assets for redistribution.
The toolkit provides no evidence of a novel research method, artist acceptance,
measured productivity gains or production use.
