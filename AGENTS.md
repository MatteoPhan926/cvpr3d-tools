# Toolkit maintenance

- Read LICENSING.md before adding code or assets. Historical research is excluded.
- Run `python -m unittest discover -s tests -v` and
  `python scripts/check_repository.py` for changes.
- Follow docs/RELEASING.md for distribution verification.
- Keep release-files.json an exact reviewed tracked-file allowlist.
- Preserve offline runtime and non-overwriting outputs.
- Do not push, merge, tag remotely or publish packages without authorization.
- Do not infer research novelty, acceptance or production quality from checks.
